# 🤝 Contributing to demo

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [dependabot/demo](https://github.com/dependabot/demo). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/demo.git

## ✅ Verify your changes

Keep changes scoped to the Dependabot demonstration and describe which dependency update behavior the change illustrates.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
